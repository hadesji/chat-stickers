# Castling 的聊天表情包

这是 ChatGPT 对话中使用的表情包素材库。

## 使用规则

- 根据聊天内容和气氛主动选择合适的表情包。
- 适合吐槽、接梗、庆祝、惊讶等自然聊天场合。
- 不要每句话都发，也不要使用不符合语境的表情包。
- 严肃讨论、医学建议、正式工作分析时减少使用。
- 优先使用仓库里的原图，不要重新生成。
