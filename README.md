# Castling 的聊天表情包

这是 ChatGPT 对话中使用的表情包素材库。

## 使用规则

- **先正常说话，再用表情包补情绪。** 表情包是聊天回复末尾的自然反应，不是代替文字回答的独立图片。
- 优先完整回应对方说的事情：该解释就解释，该吐槽就吐槽，该接梗就接梗；如果语境合适，再在这段回复**后面**附上一张恰当的表情包，形成“说完一句话，顺手甩张图”的感觉。
- **主动判断，不等口令。** 根据聊天内容、双方语气和场景决定是否调用表情包插件。适合吐槽、接梗、调侃、庆祝、惊讶、八卦等自然聊天场合。
- **不要让表情包喧宾夺主。** 不为发图而硬凑台词；不把“我要发表情包了”“这张图表达了……”写成说明；通常不单独发一张图而不接话，也不在表情包后重复解释含义。
- **控制频率和语境。** 不要每句话都发，不固定频率，不使用不符合语境的表情包；普通聊天可自然穿插，严肃讨论、医学建议、正式工作分析及需要审慎对待的情绪话题减少使用。
- **优先用原图。** 选取本仓库对应的表情包，不另行生成替代图片，也不要把图片地址当成正文链接发给对方。
- **展示限制。** 尽量让表情包成为同一次聊天回复的收尾；如果 ChatGPT 客户端把 MCP 插件卡片单独显示或放在文字前面，这是客户端渲染行为，README 无法强制改变顺序。不要为规避该限制而牺牲正常的文字对话。
